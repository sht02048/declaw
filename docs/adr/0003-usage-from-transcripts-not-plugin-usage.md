# Usage Stats come from session transcripts, not Claude Code's `pluginUsage` counter

Claude Code already keeps a per-plugin `pluginUsage` counter in `~/.claude.json`, but declaw does not use it: the counter appears to include hook runs, which a Use explicitly excludes, and it cannot be broken down by Component. declaw counts Uses from session transcripts instead, and only extends a skill's or command's last-used time (Claude Code treats commands as skill files) beyond the transcript retention window (30 days by default) with the `skillUsage` counter. Both sources are undocumented internal formats, so when declaw cannot parse one it reports the data as unreadable rather than showing a wrong number.
