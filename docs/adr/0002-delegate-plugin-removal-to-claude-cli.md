# Plugin and Standalone MCP Server removal is delegated to the `claude` CLI

declaw removes a Plugin by calling Claude Code's own `claude plugin uninstall`, and a Standalone MCP Server by calling `claude mcp remove --scope user`, instead of deleting files or editing Claude Code's config file, even though declaw already reads those files and could change them directly. The official commands also clean up plugin data and settings by Claude Code's own rules, and keep working when the internal file layout changes. When a command fails, declaw shows its error as-is rather than falling back to changing files. Old cached plugin versions are left for Claude Code's own sweep.
